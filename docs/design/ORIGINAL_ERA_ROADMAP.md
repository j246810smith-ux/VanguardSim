# Original Era content roadmap (v0.28, 2026-11-03)

The user's v0.28 spec puts Original Era content before more G era sets: (1) PR cards, (2) custom
rulings and special interactions, (3) the "Blaster Blade Burst" deck. This is the inventory and the
plan; nothing here is invented — card text comes only through the importer (official databases).

## What the game has

- **Original Era (Classic)**: BT01–BT17, TD01–TD17 (no TD15), EB01–EB12, FC01, FC02, DG01, the
  English-only BT16/BT17 cards (MBT01's 50 cards): every card scripted and tested
  (`docs/CARD_STATUS_REPORT.md`).
- **Left out so far**: MTD01 and the PR cards (user, 2026-10-30), now prioritised.

## 1. PR cards 2011–2014

Inventory taken from the official Japanese card list (`/manage/card-list-user`, products
【2011年度】–【2014年度】PRカード) on 2026-11-03: **292 PR printings**, of which **77 are reprints of
cards already in the game** (same Japanese name, nothing to do but record the printing) and
**215 are cards the game does not have yet**.

Plan:

1. Importer: accept the PR products (four-digit `PR/0001` numbers, one product per year) and the
   English printings (`PR/0001EN` …) where they exist; Japanese-only PRs get unofficial English
   in `data/translations/unofficial.json` (as FC01/BT11-055), marked as such.
2. Import in four batches, one per year (by the official yearly lists: 2011: 40, 2012: 38, 2013: 58, 2014: 79 new cards), each
   through the usual import → script → test → report loop, then a release.
3. Two entries are not Original Era clans (one Gear Chronicle, one without a clan): they go with
   the Expanded Era.

## 2. Custom rulings and special interactions

- The house-rule system exists (D-030 Delayed Legion: `GameState.customRules`, a `custom_rule`
  condition, Game Setup toggle). New rulings go in the same way: off by default, one toggle each,
  never changing the standard rules.
- Card-specific timing questions are tracked in `docs/UNRESOLVED_RULINGS.md` and get regression
  tests in `tests/abilities/`.
- Next: list the PR cards whose rulings need a decision while scripting them, and propose those
  to the user before building (repo rule).

## 3. The "Blaster Blade Burst" deck

No product of that name was found (official databases and web search, 2026-11-03). Blaster Blade
products that do exist: **TD01 "Blaster Blade"** (in the game), **G-LD01 "The Blaster Blade"**
(Legend Deck, G era: Expanded Era) and the 2026 **DZ-SS13 Start Deck** (D era: outside this
simulator). **Waiting for the user to say which deck is meant** (a product name, a set code or a
deck list) — no card list or text will be guessed.
