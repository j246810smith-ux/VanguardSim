# EFFECT KEYWORD DICTIONARY

This document maps common Vanguard card-text concepts to engine concepts.

## Timing

"When this unit attacks"
→ ATTACK_DECLARED

"When this unit's attack hits"
→ ATTACK_HIT

"When placed"
→ UNIT_PLACED

"When this unit is placed on VC"
→ UNIT_PLACED_ON_VC

"At the beginning of your main phase"
→ MAIN_PHASE_START

"At the beginning of your ride phase"
→ RIDE_PHASE_START

"At the end of the turn"
→ END_OF_TURN

## Costs

"Counter-Blast 1"
→ COUNTER_BLAST(1)

"Soul-Blast 1"
→ SOUL_BLAST(1)

"Discard a card"
→ DISCARD(1)

"Retire a rear-guard"
→ RETIRE(target)

"Rest this unit"
→ REST(source)

## Effects

"Draw a card"
→ DRAW(1)

"Choose one of your rear-guards"
→ CHOOSE_FRIENDLY_REAR_GUARD

"Call"
→ CALL

"Ride"
→ RIDE

"Add +3000 Power"
→ ADD_POWER(3000)

"Until end of turn"
→ DURATION_END_OF_TURN

"Search your deck"
→ SEARCH_DECK

"Shuffle your deck"
→ SHUFFLE_DECK

## Rule

This dictionary is a translation aid, not a substitute for reading the full card text and historical ruling.

Complex wording must be represented as a structured combination of timing, condition, cost, target and effect.
