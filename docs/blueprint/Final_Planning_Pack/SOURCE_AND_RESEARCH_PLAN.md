# SOURCE AND RESEARCH PLAN

## Purpose

Create a controlled research process for the BT01–BT17 simulator.

## Source priority

### Tier 1 — Official

Use official Bushiroad/Cardfight!! Vanguard documentation where available.

Prefer:

- historical comprehensive rules
- official card lists
- official card text
- official errata
- official rulings
- official set information

### Tier 2 — Established card databases

Use reliable databases to cross-check:

- card names
- set numbers
- stats
- card text
- rarity
- clan
- trigger
- images

### Tier 3 — Community

Use community sources for:

- discovery
- historical discussion
- edge-case identification
- cross-checking

Never use a community source as the sole authority for a disputed ruling when an authoritative source can be found.

## Research record

For disputed information record:

- card ID
- question
- source
- date/version
- conclusion
- confidence
- implementation consequence

## Conflicts

If sources disagree:

1. Preserve both values temporarily.
2. Identify printing/version.
3. Check historical rules.
4. Determine applicable date.
5. Record conclusion.
6. Add regression test if the difference affects gameplay.

## Card artwork

Use artwork that the project is legitimately permitted to use.

Do not make the game dependent on online image hosting.

Artwork should be stored locally for offline use.

## Research output

Maintain:

RESEARCH_LOG.md

and:

UNRESOLVED_RULINGS.md

No unresolved ruling should disappear silently.
