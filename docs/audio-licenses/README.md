# Audio licences

Every sound effect in the game is listed, file by file, in
`app/renderer/assets/audio/manifest/audio_assets.json` (source file, pack, URL, author, licence,
changes made). This page summarises it.

| Pack                   | Author                 | Source                                    | Licence | Files used |
| ---------------------- | ---------------------- | ----------------------------------------- | ------- | ---------- |
| Casino Audio (1.1)     | Kenney (www.kenney.nl) | https://kenney.nl/assets/casino-audio     | CC0 1.0 | 18         |
| Interface Sounds (1.0) | Kenney (www.kenney.nl) | https://kenney.nl/assets/interface-sounds | CC0 1.0 | 34         |
| Impact Sounds (1.0)    | Kenney (www.kenney.nl) | https://kenney.nl/assets/impact-sounds    | CC0 1.0 | 24         |
| Sci-Fi Sounds (1.0)    | Kenney (www.kenney.nl) | https://kenney.nl/assets/sci-fi-sounds    | CC0 1.0 | 11         |
| Music Jingles          | Kenney (www.kenney.nl) | https://kenney.nl/assets/music-jingles    | CC0 1.0 | 2          |

- **Licence:** Creative Commons Zero 1.0 (public domain dedication,
  http://creativecommons.org/publicdomain/zero/1.0/). Use in personal and commercial projects is
  allowed; attribution is not required ("Credit (Kenney or www.kenney.nl) would be nice but is not
  mandatory"). The game credits Kenney in Settings → Audio anyway.
- **Original licence files**, as shipped in each pack: `kenney-<pack>-License.txt` in this folder.
- **Downloaded** 2026-11-08 from the pages above (the "Continue without donating" download).
- **Changes:** made by `tools/audio/prepare_sfx.py`: mono 44.1 kHz, peak-normalised to -3 dB, some
  trimmed with a short fade-out, re-encoded as Ogg Vorbis. The manifest records each file's changes.

## Battle music

| File (`app/renderer/assets/audio/music/battle/`) | Title                           | Made by                      |
| ------------------------------------------------ | ------------------------------- | ---------------------------- |
| `vanguard-8-bit-battle-theme.mp3`                | Vanguard 8-Bit Battle Theme     | the project owner, with Suno |
| `vanguard-8-bit-battle-theme-1.mp3`              | Vanguard 8-Bit Battle Theme (1) | the project owner, with Suno |

Both were generated by the owner with Suno (suno.com) on 2026-10-09 and added at the owner's request on 2026-11-08. Their use follows Suno's terms for the
owner's account. The owner's files, with their tags reduced to the title (no names or account ids).

Music a player adds to their own `music` folder stays on their device and is never part of the game.

No audio comes from Cardfight!! Vanguard (games, anime or apps), Yu-Gi-Oh! Master Duel or any
other commercial product. The background music is still the game's own procedural music
(`app/renderer/audio/music.ts`), generated in code, with no recordings.
