# CARD INVENTORY — BT01–BT17

This is the master inventory that Claude Code must maintain.

## Required columns

- set
- card number
- card ID
- name
- grade
- power
- shield
- critical
- clan
- race
- type
- trigger
- rarity
- text
- effect status
- test status
- artwork status
- ruling status
- completion status

## Completion

A card is COMPLETE only when:

DATA = PASS
EFFECT = PASS
TEST = PASS
ART = PASS or explicitly reviewed as unavailable
RULING = RESOLVED
