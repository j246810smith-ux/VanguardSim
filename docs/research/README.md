# Rules research sources

The engine follows the official Cardfight!! Vanguard **Comprehensive Rules**: ver. 1.29
(2014-11-21) is the target, with ver. 1.19 (2014-02-14) and ver. 1.36 (2015-04-03) consulted for
comparison (see `docs/DECISIONS.md` D-008, D-014/D-015). Code comments cite rules as "CR <section>".
The G format (D-034) follows **ver. 1.48.1 (2018-04-02)**, cited as "CR 1.48.1 <section>"; it was
taken from the Internet Archive copy of
`en.cf-vanguard.com/wordpress/wp-content/uploads/Cardfight-Vanguard-Comprehensive-Rules180402.pdf`.

These documents are published by Bushiroad and are **not included in this repository** (D-025).
Developers who want to check a citation can download them from Bushiroad's official Cardfight!!
Vanguard websites (cf-vanguard.com / en.cf-vanguard.com) or archived copies of those pages, and
place them in `docs/research/sources/` (git-ignored) as `CR-<version>-<date>.pdf`, with a
plain-text extraction next to each (`.txt`) for searching.
