# Unresolved Rulings

Rules values or behaviours the engine needs that have **not yet been verified** against the target
rules document: **Cardfight!! Vanguard Comprehensive Rules ver. 1.29 (21 Nov 2014)**, see
`DECISIONS.md` D-008. Source text: `docs/research/sources/`.

In code, an unverified value is written `needsReview(...)`; a test fails if one is missing from this
file. A verified value is `verified(value, 'CR <section>')`; a test fails if it has no citation.
