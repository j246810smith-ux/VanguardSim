Optional card art
=================

Vanguard Sim does not include any card images. Cardfight!! Vanguard card art is
the property of Bushiroad and is not distributed with this application.

The game is fully playable without art: each card is shown as a text card with
its name, grade, power and shield.

If you own images you are entitled to use, you can place them in this folder
for personal use, one sub-folder per set, named by card number:

    cards\BT01\BT01-001.png
    cards\BT09\BT09-001.jpg

(.png or .jpg). The file name is the set code, a dash and the three-digit card
number: a card whose printed number is BT01/001EN is BT01-001.png. Restart the
game after adding images. The app reads this folder only; it never downloads
anything. Please keep the images to yourself (do not share or upload them).
