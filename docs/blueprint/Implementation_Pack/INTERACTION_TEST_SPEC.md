# INTERACTION TEST SPEC

Individual card tests are not enough.

Create cross-card and cross-mechanic tests.

## Required categories

### Combat + trigger

- Vanguard attack + Critical
- Vanguard attack + Draw
- Vanguard attack + Stand
- Vanguard attack + Heal
- Damage trigger interactions

### Ride + ability

- Ride effect
- Superior ride
- Break Ride
- Ride-related automatic effects

### Cost + effect

- Counter-Blast + effect
- Soul-Blast + effect
- Retire + effect
- Discard + effect

### Multiple effects

- simultaneous automatic effects
- optional vs mandatory effects
- player ordering
- multiple targets

### Complex mechanics

- Limit Break
- Ultimate Break
- Persona Blast
- Break Ride
- Lock
- Unlock
- Delete
- Legion

## Golden rule

Whenever a bug occurs between two mechanics, create a permanent interaction regression test.

The test should remain even after the bug is fixed.
